Field Notes

A surveyor’s toolkit of roots. Learn these and the long words start to make sense.

“-graph” = write / record

You already know it: photograph, autograph, geography.

topographycartographygeography
Remember: the /f/ in -graphy is spelt ph.

Map roots: topo- & carto-

topo- = place / land · carto- = map.

So topography = recording the shape of the land, and cartography = map-making.

Remember: root + -graphy tells you what is being recorded.

Tricky Latin twins

latitude lines run a-cross (like a ladder); longitude lines are long, top to bottom.

peninsula = paene (almost) + insula (island).

Remember: a memory hook beats a lucky guess.
